Live Pipeline — styling review

Same layout, three visual treatments

Structure is settled — source / buffer / target with an animated flow and a plain-language verdict caption. What's open is how it should look and feel. Each option below is the same content and interaction, restyled. Use the toggle in the top bar to compare each one's healthy vs. falling-behind state.

1 Console

Same palette as the rest of the app, dressed with node icons.

Closest to the current design system — light cards, DMS accent color, a small checkmark tying the target node to the Data Verification panel below it. Lowest visual risk: it reads as a natural extension of every other panel on the page rather than a new sub-language.

2 Glow

The diagram sits in its own dark "device screen," like a live feed.

The pipe diagram is set inside an inset near-black panel with a soft radial glow behind it — indigo when healthy, red when falling behind. The flowing dot gets a strong glow trail instead of a flat dot. Most dramatic option: makes the live-ness of the pipeline unmistakable, at the cost of standing out from the rest of the page's flat-card look.

3 Schematic

Reads like a wiring diagram — dense, monospace, built for engineers.

Square nodes, hairline dashed connectors, uppercase mono labels, key/value rows instead of prose, and a machine-readable verdict line (in_sync / falling_behind) with an OK/ALERT tag. Densest option: fits more real numbers on screen at once, at the cost of feeling less approachable to a first-time viewer.
